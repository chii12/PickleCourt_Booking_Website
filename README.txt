PICKLE COURT BOOKING WEBSITE
Files:
- index.html
- facilities.html
- style.css
- facilities.css
- courts.css
- script.js

Open index.html in a browser. Select Facility in the navigation to view facility amenities.
Court booking is available from the booking section on index.html.

This is a front-end prototype based on the uploaded Pickleball Digital Growth Proposal.
The booking UI, availability cards, modal confirmation, event buttons and responsive layout are client-side demo behavior.
A production version would connect these flows to a database/backend for real-time availability, customer records, automated confirmations/reminders, payments and owner/admin management.
